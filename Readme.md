# Git Helper MCP

FastMCP server for GitHub CLI (`gh`) snippets.

## Installation

- **Users (direct from GitHub, no clone)**: [INSTALL_USER.md](INSTALL_USER.md)
- **Developers (local use only)**: [INSTALL_DEV.md](INSTALL_DEV.md)

## Usage

In chat:
- `mcp_git` (lists commands)
- `mcp_git_pr` (prints PR checkout snippet)
